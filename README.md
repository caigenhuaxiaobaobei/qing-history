# 清史编纂项目

## 关于本项目

这是一份个人兴趣驱动的清史编纂资料集。出于对中国历史的热爱，以及希望系统梳理清代近三百年历史脉络的初衷，我整理了这份从入关前到清末的通史资料，涵盖通纪、典志、传记、史表、图录五个部分，共十六卷，并附有史料原文汇编。

## 编纂初衷

- **个人爱好**：历史是一面镜子。读史使人明智，修史更能加深理解。本项目是个人学习和整理的产物。
- **补全认知**：市面上关于清史的读物或失之简略，或立场先行。希望通过系统整理，呈现一个相对完整、多面的清朝历史面貌。
- **史料为证**：所有叙述尽量以原始史料为依据，重要史料原文单独汇编，便于查阅核对。
- **人民史观**：不仅关注帝王将相的庙堂史事，也致力于展现普通民众的生产生活、社会变迁和历史作用。

## 立场说明

- 本项目**不代表任何官方观点**，仅为个人学习整理的成果。
- **不站队**：既不是"明粉"，也不是"清粉"。历史不是粉圈，无需非此即彼。
- 清朝是中国历史上最后一个封建王朝，既有其历史贡献（如奠定现代中国疆域基础、多民族国家的整合），也有其历史局限（如文字狱、闭关锁国、后期的腐朽没落）。两者都是历史事实，不应因偏好而偏废。
- 评价历史人物和事件，力求放在具体的历史语境中考察，不做简单的善恶标签化。

## 内容结构

```
清史/

├── 通纪卷一 ~ 卷九            # 通纪：按时间顺序叙述清代历史
├── 典志卷十                   # 典志：典章制度专史
├── 传记卷十一 ~ 卷十三        # 传记：重要人物传记

├── 图录卷十六                 # 图录：历史图像资料

```

## 编纂过程

1. **大纲拟定**：参考历代正史体例，结合现代史学研究成果，拟定十六卷编纂大纲。
2. **史料搜集**：以《清实录》《清史稿》为主干，辅以《东华录》《圣武记》《明季南略》等私家著述，以及近现代史学研究成果。
3. **分卷编纂**：按通纪、典志、传记、史表、图录五大部分依次推进。
4. **交叉审核**：各卷完成后进行通读审核，校正史实错误，统一体例。
5. **图像整理**：图录卷所用图片均来自公共领域历史资源（Wikimedia Commons、美国国会图书馆等），不使用AI生成图像。
